## Uploading V2.9 source

1. Download the file `GCSE_LanPya_V2_9_Variation_Selection_Native_Source.zip` from the ChatGPT conversation.
2. Extract the ZIP, then enter the `GCSE_LanPya_V2_9` folder.
3. Copy **the contents of that folder** to the repository root, retaining the `app/`, `.github/`, `content/`, `scripts/`, Gradle files, and `validate_content_v2_9.py`.
4. Commit and push those files to `main` (or use the accompanying Windows upload script).
5. Open **Actions → GCSE LanPya Android Build**, run the workflow, and check whether a debug APK artifact is created.
